# Camera–LiDAR Fusion

Ongoing research by **Minjae Kim**, a graduate student at Dongguk University.

## Research interest

This project explores how camera images and LiDAR measurements can provide complementary visual and geometric information for perception.

## Current status

Research is in progress. This public repository currently contains a project overview; implementation code, datasets, trained weights, and benchmark results have not been released here.
